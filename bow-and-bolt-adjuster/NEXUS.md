# Bow-and-Bolt Adjuster

## Description
A cheat mod that lets you tune the crossbow and its bolts from an in-game menu. The Witcher 3 has no bow, so the "Bow" settings apply to the crossbow.

## Installation instructions
**Vortex:**
1. Install the ZIP with Vortex and enable it.
2. Double-click `install.bat` in your game folder once so the menu shows up.

**Manual:**
1. Unpack the ZIP and copy everything inside (`Mods`, `bin`, `install.bat`) into your Witcher 3 game folder.
2. Double-click `install.bat` there.

**Uninstall:** delete `Mods\modBowAndBoltAdjuster` and `bin\config\r4game\user_config_matrix\pc\modBowAndBoltAdjuster.xml`.

## Main features
Menu: **Options → Mods → Cheats**

**Bow_Settings (crossbow)**
- Mod on/off
- Fire speed: 1x to 10x
- Shots before reload: 1, 2, 3, 5, 10, 25 or Automatic (never reload)
- Reload speed: 1x to 10x

**Bolt_Settings**
- Bolt speed: slider 1x to 1000x
- Bolt damage: 1x to 100000x

Known limits: menu texts use underscores, very fast bolts can pass through enemies, fire speed briefly speeds up Geralt while aiming. Not tested in game yet.

## Requirements
- The Witcher 3 Next-Gen, version 4.0 or newer
- No Script Merger needed
