## English

Cheat mod for **The Witcher 3 – Next-Gen (version 4.0 or newer)**.
Adjusts the crossbow and bolts from the in-game menu.

> Note: Witcher 3 has no bow, only the crossbow. "Bow-Settings" applies to the crossbow.

### Features

In game under **Options → Mods → Cheats**:

**Bow_Settings (crossbow)**
- Mod on/off
- Fire speed: 1x to 10x
- Shots before reload: 1, 2, 3, 5, 10, 25 or **Automatic** (never reload)
- Reload speed: 1x to 10x

**Bolt_Settings (bolts)**
- Speed: slider 1x to 1000x
- Damage: choose 1x to 100000x

### Install with Vortex

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases).
2. Drag the ZIP into Vortex (Mods → drop file here), then **Install** and **Enable**.
3. Double-click `install.bat` in the game folder once so the menu shows up.

### Manual install (3 steps)

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases) and unpack it.
2. Copy **everything inside** (`Mods`, `bin`, `install.bat`) into your Witcher 3 game folder.
   Steam example: `C:\Program Files (x86)\Steam\steamapps\common\The Witcher 3`
3. Double-click `install.bat` there. Done.

### Known limits

- Menu texts are not translated yet (underscores instead of spaces).
- Very high bolt speed can make bolts pass through enemies.
- Fire speed briefly speeds up Geralt's movement while aiming.
- Not tested in game yet. Please report bugs.

### Uninstall

Delete the folder `Mods\modBowAndBoltAdjuster` and the file
`bin\config\r4game\user_config_matrix\pc\modBowAndBoltAdjuster.xml`.

## Deutsch

Cheat-Mod für **The Witcher 3 – Next-Gen (Version 4.0 oder neuer)**.
Stellt die Armbrust und die Bolzen im Spielmenü ein.

> Hinweis: In Witcher 3 gibt es keinen Bogen, nur die Armbrust. „Bow-Settings“ gilt also für die Armbrust.

### Was die Mod kann

Im Spiel unter **Optionen → Mods → Cheats**:

**Bow_Settings (Armbrust)**
- Mod an/aus
- Schussgeschwindigkeit: 1x bis 10x
- Schüsse vor dem Nachladen: 1, 2, 3, 5, 10, 25 oder **Automatik** (nie nachladen)
- Nachlade-Tempo: 1x bis 10x

**Bolt_Settings (Bolzen)**
- Geschwindigkeit: Schieber 1x bis 1000x
- Schaden: Auswahl 1x bis 100000x

### Installieren mit Vortex

1. Die ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) herunterladen.
2. Die ZIP in Vortex ziehen (Mods → Datei hier ablegen), dann **Installieren** und **Aktivieren**.
3. Einmal `install.bat` im Spielordner doppelklicken, damit das Menü erscheint.

### Installieren von Hand (3 Schritte)

1. Die ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) herunterladen und entpacken.
2. **Alles darin** (`Mods`, `bin`, `install.bat`) in den Witcher-3-Spielordner kopieren.
   Beispiel Steam: `C:\Program Files (x86)\Steam\steamapps\common\The Witcher 3`
3. Dort `install.bat` doppelklicken. Fertig.

### Bekannte Grenzen

- Die Menütexte sind noch nicht übersetzt (Unterstriche statt Leerzeichen).
- Sehr hohe Bolzen-Geschwindigkeit kann dazu führen, dass Bolzen durch Gegner „durchfliegen“.
- Schussgeschwindigkeit beschleunigt Geralts Bewegung beim Zielen kurz mit.
- Noch nicht im Spiel getestet. Fehler bitte melden.

### Deinstallieren

Ordner `Mods\modBowAndBoltAdjuster` und die Datei
`bin\config\r4game\user_config_matrix\pc\modBowAndBoltAdjuster.xml` löschen.
