# Bow-and-Bolt Adjuster

Repository: https://github.com/djdomi/witcher3-mods · License: [AGPL-3.0](https://github.com/djdomi/witcher3-mods/blob/main/LICENSE)

## English

Cheat mod for **The Witcher 3 – Remastered (version 5.0 or newer)**.
Adjusts the crossbow and bolts from the in-game pause menu.

> Note: Witcher 3 has no bow, only the crossbow. "Bow" means the crossbow.

### Features

In game: open the **pause menu → Mod Menu → Bow and Bolt**.

**Crossbow**
- Mod on/off
- Fire speed: 1x to 10x
- Shots before reload: 1, 2, 3, 5, 10, 25 or **Automatic** (never reload)
- Reload speed: 1x to 10x

**Bolts**
- Speed: slider 1x to 1000x
- Damage: choose 1x to 100000x

### Install with Vortex

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases).
2. Drag the ZIP into Vortex (Mods → drop file here), then **Install**, **Enable** and **Deploy**.

### Manual install

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases) and unpack it.
2. Copy `Mods` and `bin` into your Witcher 3 game folder. Done.

### Known limits

- Very high bolt speed can make bolts pass through enemies.
- Fire speed briefly speeds up Geralt's movement while aiming.

### Uninstall

Disable the mod in Vortex, or delete the folder `Mods\modBowAndBoltAdjuster` and the file
`bin\config\r4game\user_config_matrix\pc\modBowAndBoltAdjuster.xml`.

## Deutsch

Cheat-Mod für **The Witcher 3 – Remastered (Version 5.0 oder neuer)**.
Stellt die Armbrust und die Bolzen im Pausemenü ein.

> Hinweis: In Witcher 3 gibt es keinen Bogen, nur die Armbrust. „Bow“ meint die Armbrust.

### Was die Mod kann

Im Spiel: **Pausemenü → Mod Menu → Bow and Bolt** öffnen.

**Armbrust**
- Mod an/aus
- Schussgeschwindigkeit: 1x bis 10x
- Schüsse vor dem Nachladen: 1, 2, 3, 5, 10, 25 oder **Automatik** (nie nachladen)
- Nachlade-Tempo: 1x bis 10x

**Bolzen**
- Geschwindigkeit: Schieber 1x bis 1000x
- Schaden: Auswahl 1x bis 100000x

### Installieren mit Vortex

1. Die ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) herunterladen.
2. Die ZIP in Vortex ziehen (Mods → Datei hier ablegen), dann **Installieren**, **Aktivieren** und **Deploy**.

### Installieren von Hand

1. Die ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) herunterladen und entpacken.
2. `Mods` und `bin` in den Witcher-3-Spielordner kopieren. Fertig.

### Bekannte Grenzen

- Sehr hohe Bolzen-Geschwindigkeit kann dazu führen, dass Bolzen durch Gegner „durchfliegen“.
- Schussgeschwindigkeit beschleunigt Geralts Bewegung beim Zielen kurz mit.

### Deinstallieren

Mod in Vortex deaktivieren, oder den Ordner `Mods\modBowAndBoltAdjuster` und die Datei
`bin\config\r4game\user_config_matrix\pc\modBowAndBoltAdjuster.xml` löschen.
