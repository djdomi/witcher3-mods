# All Skills & Mutations

## English

Cheat mod for **The Witcher 3 – Next-Gen (version 4.0 or newer)**.

### Features

- **All learned skills work at the same time**, even without a slot.
- **All researched mutations work at the same time** (Blood and Wine). Keep one mutation equipped as usual, the others work on top.

Toggle in game under **Options → Mods → Cheats → All_Skills_Mutations**.
Both are **on** by default. Takes effect after about 2 seconds, also in old saves.

Same idea as the known mods "All Skills Always Active" and "Slots Slots SLOTS", but written from scratch and without Script Merger.

### Install with Vortex

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases).
2. Drag the ZIP into Vortex, then **Install** and **Enable**.
3. Double-click `install.bat` in the game folder once so the menu shows up.

### Manual install

1. Download the ZIP and unpack it.
2. Copy **everything inside** (`Mods`, `bin`, `install.bat`) into your Witcher 3 game folder.
3. Double-click `install.bat` there. Done.

### Important

- **Before uninstalling:** switch both toggles **off**, wait a moment, then save. Otherwise bonuses stay in the save.
- Do not combine with other mods that change skills or mutations.
- Some mutations exclude each other in the game (e.g. 4/5/7/8/10 for adrenaline). The first one wins.
- Not tested in game yet. Please report bugs.

### Uninstall

Delete the folder `Mods\modAllSkillsMutations` and the file
`bin\config\r4game\user_config_matrix\pc\modAllSkillsMutations.xml`.

## Deutsch

Cheat-Mod für **The Witcher 3 – Next-Gen (Version 4.0 oder neuer)**.

### Was die Mod kann

- **Alle gelernten Fähigkeiten wirken gleichzeitig**, auch ohne Slot.
- **Alle erforschten Mutationen wirken gleichzeitig** (Blood and Wine). Eine Mutation musst du weiter normal einsetzen, die anderen wirken zusätzlich.

Ein- und ausschalten im Spiel unter **Optionen → Mods → Cheats → All_Skills_Mutations**.
Beides ist ab Start **an**. Wirkt nach ca. 2 Sekunden, auch in alten Spielständen.

Idee wie bei den bekannten Mods „All Skills Always Active“ und „Slots Slots SLOTS“, aber selbst geschrieben und ohne Script Merger.

### Installieren mit Vortex

1. Die ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) herunterladen.
2. Die ZIP in Vortex ziehen, dann **Installieren** und **Aktivieren**.
3. Einmal `install.bat` im Spielordner doppelklicken, damit das Menü erscheint.

### Installieren von Hand

1. ZIP herunterladen und entpacken.
2. **Alles darin** (`Mods`, `bin`, `install.bat`) in den Witcher-3-Spielordner kopieren.
3. Dort `install.bat` doppelklicken. Fertig.

### Wichtig

- **Vor dem Deinstallieren:** im Menü beide Schalter **aus**, kurz warten, dann speichern. Sonst bleiben Boni im Spielstand.
- Nicht zusammen mit anderen Mods nutzen, die Fähigkeiten oder Mutationen ändern.
- Manche Mutationen schließen sich im Spiel gegenseitig aus (z. B. 4/5/7/8/10 beim Adrenalin). Dann gewinnt die erste.
- Noch nicht im Spiel getestet. Fehler bitte melden.

### Deinstallieren

Ordner `Mods\modAllSkillsMutations` und die Datei
`bin\config\r4game\user_config_matrix\pc\modAllSkillsMutations.xml` löschen.
