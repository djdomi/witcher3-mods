# All Skills & Mutations

## Description
A cheat mod that makes all learned skills and all researched mutations work at the same time, without needing free slots.

## Installation instructions
**Vortex:**
1. Install the ZIP with Vortex and enable it.
2. Double-click `install.bat` in your game folder once so the menu shows up.

**Manual:**
1. Unpack the ZIP and copy everything inside (`Mods`, `bin`, `install.bat`) into your Witcher 3 game folder.
2. Double-click `install.bat` there.

**Before uninstalling:** switch both toggles off, wait a moment, then save. Otherwise the bonuses stay in your save.
**Uninstall:** delete `Mods\modAllSkillsMutations` and `bin\config\r4game\user_config_matrix\pc\modAllSkillsMutations.xml`.

## Main features
- All learned skills work at the same time, even without a slot.
- All researched mutations (Blood and Wine) work at the same time. Keep one mutation equipped as usual, the others work on top.
- Toggle in game under **Options → Mods → Cheats → All_Skills_Mutations**. Both are on by default.
- Works in old saves, takes effect after about 2 seconds.

Known limits: do not combine with other mods that change skills or mutations. Some mutations exclude each other in the game; the first one wins. Not tested in game yet.

## Requirements
- The Witcher 3 Next-Gen, version 4.0 or newer
- Blood and Wine for mutations
- No Script Merger needed
