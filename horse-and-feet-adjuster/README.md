# Horse and Feet Adjuster

English · [Deutsch](#deutsch)

Mod for **The Witcher 3 Remastered (version 5.0 or newer)**. Makes Geralt run faster on foot and makes the horse faster. Hold **ALT** for an extra boost.

## Features

- **Running speed on foot:** x1 (normal) to x5. Only while running or sprinting, only outside combat. Walking and fighting stay normal.
- **Horse speed:** x1 (normal) to x5, while the horse moves.
- **ALT boost:** hold ALT (the game's "walk" key) and the speed is multiplied again, x1 to x5 (default x2). Works on foot and on the horse.
- Every part has its own on/off switch.

## Settings

In game: pause menu, **Mod Menu**, then **Horse and Feet Adjuster**.

| Setting | Default |
|---|---|
| Mod enabled | on |
| On foot: change running speed | on |
| On foot: running speed (x) | 1 |
| Horse: change speed | on |
| Horse: speed (x) | 1 |
| Hold ALT for boost | on |
| ALT boost (x) | 2 |

## Install with Vortex

1. Download the ZIP from [Releases](https://github.com/djdomi/witcher3-mods/releases).
2. Drag the ZIP into Vortex, then **Install** and **Enable**.
3. Start the game. Done.

## Manual install

Unpack the ZIP and copy the folders `Mods` and `bin` into your Witcher 3 game folder.

## Uninstall

Disable/remove it in Vortex, or delete the folder `Mods\modHorseAndFeetAdjuster`, the file `bin\config\r4game\user_config_matrix\pc\modHorseAndFeetAdjuster.xml` and the file `bin\config\base\horseandfeetadjuster.ini`.

## Notes

- With "Hold ALT for boost" on, ALT no longer switches walk mode (on foot) or the horse pace. Switch it off to get the normal ALT back.
- The speed-up makes the animations faster. That is how Geralt and the horse move faster.
- If you changed the walk key in the game, the boost uses your key.
- Not tested in game yet. Please report bugs.

# Deutsch

Mod für **The Witcher 3 Remastered (Version 5.0 oder neuer)**. Geralt rennt zu Fuß schneller und das Pferd wird schneller. **ALT** halten gibt einen Extra-Schub.

## Was die Mod kann

- **Renngeschwindigkeit zu Fuß:** x1 (normal) bis x5. Nur beim Rennen oder Sprinten, nur außerhalb vom Kampf. Gehen und Kämpfen bleiben normal.
- **Pferde-Tempo:** x1 (normal) bis x5, solange das Pferd läuft.
- **ALT-Schub:** ALT (die "Gehen"-Taste des Spiels) halten, dann wird das Tempo nochmal multipliziert, x1 bis x5 (Standard x2). Geht zu Fuß und auf dem Pferd.
- Jeder Teil hat einen eigenen An/Aus-Schalter.

## Einstellungen

Im Spiel: Pausemenü, **Mod Menu**, dann **Horse and Feet Adjuster**.

| Einstellung | Standard |
|---|---|
| Mod enabled | an |
| On foot: change running speed | an |
| On foot: running speed (x) | 1 |
| Horse: change speed | an |
| Horse: speed (x) | 1 |
| Hold ALT for boost | an |
| ALT boost (x) | 2 |

## Installation mit Vortex

1. ZIP unter [Releases](https://github.com/djdomi/witcher3-mods/releases) laden.
2. ZIP in Vortex ziehen, dann **Installieren** und **Aktivieren**.
3. Spiel starten. Fertig.

## Manuelle Installation

ZIP entpacken und die Ordner `Mods` und `bin` in den Witcher-3-Spielordner kopieren.

## Deinstallation

In Vortex deaktivieren/entfernen, oder den Ordner `Mods\modHorseAndFeetAdjuster`, die Datei `bin\config\r4game\user_config_matrix\pc\modHorseAndFeetAdjuster.xml` und die Datei `bin\config\base\horseandfeetadjuster.ini` löschen.

## Hinweise

- Wenn "Hold ALT for boost" an ist, schaltet ALT nicht mehr in den Gehen-Modus (zu Fuß) und nicht mehr die Pferde-Gangart. Schalter aus = ALT wieder normal.
- Die Mod macht die Animationen schneller. So bewegen sich Geralt und das Pferd schneller.
- Wenn du die Gehen-Taste im Spiel geändert hast, nutzt der Schub deine Taste.
- Noch nicht im Spiel getestet. Fehler bitte melden.
